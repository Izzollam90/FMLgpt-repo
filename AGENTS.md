# Repository agent instructions (planning branch)
This repository contains AI-assisted small-business agency planning materials. Avoid unrelated modifications to existing code.

## Safety and scope
- Work only in the requested files and branch; provide diff/summary before merges and deployments.
- Never delete or overwrite existing user/customer work without verified backups and explicit approval.
- Never run commands altering disks, partitions, bootloaders, encryption or operating systems.
- Never expose secrets, private client data, payment credentials or SSH keys.
- Require approval before purchases, billing changes, outbound emails/calls, ads, social posts, domain changes and production deploys.
- For generated marketing: verify model licenses and permissions for likeness, music, images and brand assets. Never fabricate endorsements, claims or results.
- Prefer smallest change that solves the identified task. Run tests before claiming anything works.
- When uncertain about contracts, privacy, phone/SMS consent or licensing, mark it for human review.
- Do not use privileged system access or browser credentials to shortcut human approval.
- Do not present autonomous agent execution, local inference or a demo website as a customer-ready production service until independently tested.

## Current focus
Read `docs/ai-agency/README.md` and `docs/ai-agency/ROADMAP.md`. The priority is one paid client, a truthful portfolio, and a low-cost workflow. Voice automation is future work.
