# Existing GitHub assets: reuse before forking more
**Repository inventory checked:** October 22, 2026. These repositories are present on the connected account, not verified as tested/functional deployments.

| Repository | Reuse | Caution |
|---|---|---|
| [bolt.new](https://github.com/Izzollam90/bolt.new) | Study the familiar Bolt approach | Upstream source/fork; do not mix client code into framework |
| [motion-video-kit](https://github.com/Izzollam90/motion-video-kit) | Video creation, critique and QA process | Evaluate sample outcomes and asset licensing |
| [VoiceStudio](https://github.com/Izzollam90/VoiceStudio) | Future synthetic voice / TTS evaluation | AGPL and model licenses matter; user consent required |
| [LCM](https://github.com/Izzollam90/LCM) | Clearly-labeled website portfolio concept | Private repo; don't publish, alter or deploy without reviewing; no claim of active partnership |
| [agentskills](https://github.com/Izzollam90/agentskills) | Portable SKILL.md instructions | Evaluate untrusted third-party prompts and scripts |
| [plugins](https://github.com/Izzollam90/plugins) | Plugin development reference | Large dependency surface; do not install everything |
| [FMLgpt-repo](https://github.com/Izzollam90/FMLgpt-repo) | Planning branch for AI marketing agency | Public repository; no customer secrets or private discussions |

**Do not fork more yet:** AI training framework, production voice receptionist, hosted chatbot app, another code agent, video model zoo. Test a specific useful task, record result, and only then add dependencies.

## Recommended later structure
- One **private** repository per client.
- One agency portfolio/source repository with only rights-cleared demonstrations.
- Separate shared templates and reusable skills repository when there are 2+ actual repeat uses.
- Never store access keys or client private data in this repository.

This plan is staged only on `planning/ai-agency-launch-2026-10` and has not been merged into the default branch.
